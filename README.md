## 人工智能的原理与应用--挖掘传统文化智慧

### 人工智能与传统文化智慧--大道至简

人工智能既不是新科技也不是高科技，其原理极其简单，无论懂与不懂，我们都在不知不觉中大量使用，易经道德经甚至民间俗语，都有关于人工智能的描述，因为太简单太平凡，以至于被忽略到了无视的境地，正如道德经对道的描述，仁者见仁智者见智，百姓日用而不自知。
   
人工智能与我们乃至整个宇宙息息相关，理解人工智能的原理，能帮助我们更好的工作生活，认识这个世界，你会明白为什么幸运的人总幸运，倒霉的人总倒霉，有钱的人总有钱，为什么有马太效应二八定律，以及整个宇宙是如何运行的。

### 爱迪生的电灯--试错

人工智能源于对人类智能的模仿，首先让我们看看地球上最聪明的一批人是如何解决问题的，他们到底具有多少智能。

爱迪生制造电灯的时候，选择何种材料作为灯丝是个难题，爱迪生也没有什么好办法，只能一遍一遍的尝试，把能用的材料都试一遍，排除不合适的材料，剩下的就是最正确的选择，是的，地球上最聪明的一批人，就是用这种简单粗暴的方法解决问题的，和密码的暴力破解一个道理，把所有的密码都试一遍，总会有一个正确的。

没有什么问题是试一遍解决不了的，把所有的可能性都试一遍，总会有一个正确的，所以说实践出真知，实践才是检验真理的唯一标准，科学发展到今天更是大量实验试错的结果，是骡子是马拉出来遛遛。

爱迪生说天才是百分之一的灵感加百分之九十九的汗水，那一次灵感正是无数次试错的结果，某一次试错恰好得出了正确结果，灵感就出现了，每一次试错就会排除一个错误选项，试错的次数越多离正确结果越近，所以说失败是成功之母，人类的出现更是大自然无数次试错的结果。
　　　
### 盲人打靶--训练

假如让盲人参加射击比赛，怎样才能击中靶心呢？很简单，随机射击就行了，理论上只要射击的次数足够多，就有概率击中靶心，但有一个问题，这种暴力试错及其耗费时间，运气不好到宇宙灭亡的那天都无法击中靶心，可见单纯的依靠试错效率极其低下。

这时候就需要一个教练在旁边指导，反馈射击误差，盲人根据反馈的误差调整射击角度，几轮调整下来射击的误差会越来越小，直至击中靶心，大大降低了试错的次数，这个过程完整展示了人工智能的工作方式，随机开枪相当于初始化参数，教练测量误差后反向传播优化参数，经过几轮迭代使误差趋近于零，最终求解出最小损失函数，这就是人工智能的训练过程。

我们的大脑也是这样工作的，最初学走路大脑并不清楚该如何调整肌肉，没有什么好办法，只能不断的尝试，一次次跌倒一次次爬起，最终把肌肉调整到一个最佳状态，这也是运动员训练的意义所在。熟能生巧，功到自然成，读书破万卷下笔如有神，书读百遍其意自见，这些俗话说的都是训练的重要性。

所以智能这东西根本不存在，只是大脑欺骗你的一种假象，你所认为的智能，其本质就是通过大量试错排除错误选项，逐步缩小范围找到最优解的方法，人类的智慧情感直觉都来源于此。总结一句话，我们的大脑用了一种无脑的方式解决复杂问题。

### 下课时间--梯度下降

老师在讲课，想知道下课时间就要不停的看手表，显然这会浪费大量时间干扰讲课，而加大看手表的间隔又可能错过下课时间，这就需要进行动态的调整，一开始间隔较长，随着下课临近逐渐缩短间隔，这样既能准时下课又不浪费过多精力，这就是梯度下降，大幅度减少试错成本。

### 强化与弱化

能量总是有限的，面对残酷的竞争，生物要想在自然选择中生存下来，合理使用每一份能量就显得尤为重要，好钢用在刀刃上，经常用的说明很重要，要增加能量供给强化它，不常用的就要弱化，不让它浪费能量，就像杂物间，不常用的要打包收起来甚至丢弃从而使空间利用更有效率，这就是为什么运动员经常锻炼肌肉就会变得发达，瘫痪的人不活动肌肉就会萎缩。

这种现象在基因表达上尤为明显，老鹰善于飞翔，猎豹善于奔跑，鲨鱼善于游泳，都是常用基因被强化的结果，而人有了聪明的大脑，这些优势基因逐渐被弱化直至抛弃，甚至具有重要保护功能的皮毛也被削弱，节省的能量都被用来强化大脑，生物不存在进化与退化, 只有强化与弱化, 我们看到的所有生物特征都是强化与弱化的结果。

神经网络像肌肉一样也会被强化与弱化，就像一个带有电容的放大器，每用一次就会充一次电，使用次数越多充电越足放大能力越强，这条网络就会得到强化，信号就会优先到达，而不经常用的网络就会被弱化无法传递信号，通过强化与弱化的复杂组合神经网络就能准确的处理信息控制肌肉的运动，这也是记忆产生的原因，记忆不仅存在与大脑，而是存在于每一个被强化的细胞。

你可以把每个问题都想象成一把锁，解决问题的过程就是尝试用不同的钥匙开锁的过程，大脑通过神经网络的不同强化组合生成无数钥匙，然后依次测试开锁，直到找到正确的钥匙。换句话说大脑里储存的就是一堆密钥。

我们所看到的宇宙中的一切一切也都是强化与弱化的结果，从这个意义上说，整个宇宙就是一个智能体。

### 正反馈与负反馈

有了钱就可以买到资产，有了资产就可以赚到钱，进而买更多的资产赚更多的钱，这就形成了正反馈，正反馈导致强化，负反馈抑制正反馈弱化，
